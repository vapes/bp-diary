# Дневник артериального давления

Простое офлайн веб-приложение в одном файле (`index.html`): записывайте давление и пульс,
смотрите графики и печатайте отчёт для врача.

## Как пользоваться

- Откройте `index.html` в браузере (или страницу GitHub Pages этого репозитория).
- Вводите дату/время, верхнее (САД) и нижнее (ДАД) давление, пульс, руку и заметку.
- Отчёт за 7 / 14 / 30 / 90 дней или всё время: средние ± SD, доля измерений выше 135/85,
  утро/вечер, графики давления и пульса, сравнение рук, распределение по категориям ESH 2023.
- «Отчёт для врача / PDF» — печать или сохранение в PDF.
- Языки: русский и польский. Язык интерфейса (RU/PL вверху) и язык отчёта выбираются отдельно —
  можно вести дневник по-русски, а отчёт и CSV для врача получать по-польски.
  Заметки печатаются как написаны (не переводятся).

## Установка на телефон

Это PWA: откройте страницу GitHub Pages и выберите «Установить приложение»
(Android / Chrome) или «Поделиться → На экран Домой» (iPhone / Safari).
После установки работает без интернета.

## Данные

Записи хранятся только в браузере на этом устройстве (localStorage) и никуда не отправляются.
Делайте резервную копию (JSON) — из неё можно восстановить данные; CSV открывается в Excel.

Категории давления — ориентир, а не диагноз.

## Android-приложение (APK)

Папка `android/` — нативная оболочка (Kotlin + WebView) вокруг того же `index.html`.
Отличия от браузерной версии: данные в памяти приложения (не стираются при очистке браузера,
попадают в автокопию Android), сохранение CSV/JSON через системный диалог, печать/PDF через Android.
Без разрешения на интернет — данные не покидают телефон.

APK собирает GitHub Actions (`.github/workflows/android.yml`) при каждом пуше в `main`
и публикует в Releases: https://github.com/vapes/bp-diary/releases/latest/download/bp-diary.apk

Подпись: `android/keystore/release.p12`, защищён паролем из секрета репозитория `SIGNING_PASSWORD`
(Settings → Secrets and variables → Actions). Без секрета APK подписывается временным ключом и в Releases не публикуется.
Ключ нельзя менять: иначе новую версию нельзя будет установить поверх старой.
